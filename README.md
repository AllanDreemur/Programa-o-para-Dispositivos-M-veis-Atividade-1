# app_localizacoes

Atividade 1 – Coleta e visualização de localizações
Programação para Dispositivos Móveis II – Fatec

## Integrantes

- Gabriel Camargo Prado.

## Funcionalidades

- Coleta contínua de localização por stream (alta precisão, intervalo de 20 s)
- Serviço em primeiro plano com notificação (Android)
- Persistência em SQLite (`localizacoes.db`)
- Histórico das últimas 100 posições, com opção de limpar
- Mapa interativo (OpenStreetMap) com cache local dos tiles
